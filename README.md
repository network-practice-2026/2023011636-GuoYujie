# 2023011636-郭宇杰 计算机网络知识体系交互式展示系统

本项目用于《网络实习》课程，目标是实现一个集协议原理动态展示、综合网络场景模拟、TCP/IP 五层模型知识管理与知识图谱于一体的交互式学习系统。

## 技术栈

- 前端：HTML、CSS、原生 JavaScript
- 后端：Python 标准库 HTTP 服务
- 数据库：SQLite

选择该方案的原因是依赖少、易运行、易修改，适合课程实习阶段逐步实现和展示。

## 目录结构

```text
2023011636-郭宇杰/
├── app.py                 # 后端服务入口
├── database.py            # SQLite 初始化与基础查询
├── schema.sql             # 数据库建表脚本
├── data/                  # SQLite 数据库文件目录
├── public/                # 前端页面与静态资源

```

## 运行方法

```bash
python app.py
```

启动后访问：

```text
http://127.0.0.1:8000
```

## 功能模块

1. 协议可视化
   - DNS 域名解析过程展示
   - DNS 缓存命中、未命中和缓存表更新
   - TCP 三次握手与四次挥手动画
   - 支持逐步播放与自动播放

2. 综合模拟过程
   - 按步骤展示 H1 访问 `www.abc.com` 从 t0 到 t1 的通信过程
   - 展示 ARP、DNS、TCP、HTTP 相关帧/报文
   - 动态展示 H1 ARP 表和交换机 S 交换表
   - 支持步骤目录、自动播放、重播动画和协议封装视图

3. 知识库
   - 基于 SQLite 存储 TCP/IP 五层模型知识点
   - 支持知识点查询、新增、编辑、删除
   - 支持知识库 JSON 导出

4. 知识图谱
   - 使用 3D 图谱展示计算机网络知识体系
   - 支持节点点击、聚焦、层级显示和详情查看
