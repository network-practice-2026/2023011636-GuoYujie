## 一、协议可视化

模块一用于展示基础网络协议或二层机制的动态过程，目前包含四个子模块。

### DNS 域名解析

覆盖内容：

- 客户端、DNS 服务器和目标域名输入框
- 用户输入域名后，逐步展示 DNS 查询过程
- 展示缓存命中与缓存未命中
- 展示最终解析出的 IP 地址
- 展示 DNS 缓存表查询和更新结果
- 支持下一步、自动播放、重置、清空缓存

### TCP 连接管理

覆盖内容：

- 客户端和服务器
- 建立连接和释放连接两种演示模式
- SYN、ACK、FIN 等报文动画
- CLOSED、SYN-SENT、ESTABLISHED、FIN-WAIT 等状态变化
- 展示连接建立或释放结果
- 支持下一步、自动播放和重置

### ARP 地址解析

覆盖内容：

- 源主机 H1、目标主机 H2、交换机 S1、交换机 S2
- 源主机已知目标 IP、未知目标 MAC 的初始状态
- ARP Request 广播过程
- 两个交换机对广播帧的转发过程
- ARP Reply 单播返回过程
- H1 ARP 缓存表写入 IP 与 MAC 映射结果

### 交换机转发与 MAC 地址表学习

覆盖内容：

- H1、H2、H3、H4 和交换机 S
- 主机发送数据帧过程
- 交换机学习源 MAC 地址过程
- 目的 MAC 未知时泛洪
- 目的 MAC 已知后定向转发
- MAC 地址表动态变化

## 二、模拟过程

模块二根据课程题目给定拓扑，展示 H1 从 t0 时刻访问 `www.abc.com`，到 t1 时刻交换机第一次收到封装 HTTP 请求报文的以太网帧之前的完整通信过程。

拓扑要点：

- H1、H2、本地域名服务器、路由器 R 连接到以太网交换机 S
- 路由器 R 连接 Internet
- Web 服务器位于 Internet 中
- 初始状态下 H1 ARP 表和交换机 S 交换表为空

页面能力：

- 支持开始、上一步、下一步、重播动画、自动播放、重置
- 支持步骤目录跳转
- 按步骤展示当前通信的起点、终点、协议、通信方式
- 展示源 MAC、目的 MAC、源 IP、目的 IP
- 在拓扑图中动态展示帧或报文路径
- 展示交换机 S 的处理行为
- 动态更新 H1 ARP 表
- 动态更新交换机 S 交换表
- 展示协议封装视图，包括应用层、传输层、网络层、数据链路层
- 最终给出从 t0 到 t1 的状态和结论

该模块补充分析了本地域名服务器在没有外部解析缓存时，需要向默认网关 R 进行 ARP 解析并向外部 DNS 查询的过程，因此 t0 到 t1 中也包含这些额外以太网帧对交换机学习表的影响。

## 三、知识库

模块三用于管理 TCP/IP 五层模型知识点，知识点不是写死在页面中，而是存储在 SQLite 数据库中，并通过接口完成增删改查。

主要能力：

- 左侧以 TCP/IP 五层模型目录展示层级关系
- 支持上一层、下一层切换
- 支持按层级展示知识点
- 支持搜索知识点、协议或说明
- 支持新增知识点
- 支持编辑知识点
- 支持删除知识点
- 支持导出 JSON
- 支持“显示英文 / 隐藏英文”切换

英文显示功能示例：

- 应用层（Application Layer）
- 传输层（Transport Layer）
- 网络层（Network Layer）
- 数据链路层（Data Link Layer）
- 物理层（Physical Layer）
- TCP（Transmission Control Protocol）
- DNS（Domain Name System）
- ARP（Address Resolution Protocol）

英文名词仅用于展示，不会写入数据库，不影响新增、编辑、删除和搜索的原始中文数据。

## 四、知识图谱

模块四使用 3D 知识图谱展示计算机网络知识体系。

主要能力：

- 顶层节点为“计算机网络”
- 下一层为 TCP/IP 五层模型
- 再下一层为各层对应协议、设备、技术、机制、概念等知识点
- 点击节点后显示知识点详情
- 支持节点聚焦
- 支持拖动、缩放和旋转视角
- 支持选择显示层数
- 支持重置图谱
- 支持“显示英文 / 隐藏英文”切换

知识库与知识图谱已实现双向联动：

- 在知识库中点击“图谱查看”，会跳转到知识图谱并聚焦对应知识点
- 在知识图谱中点击节点后，可跳转回知识库查看对应条目或对应层级
- 新增、编辑、删除知识点后，知识图谱会读取数据库中的最新知识点

知识图谱数据与知识库取并集，以数据库中当前保存的知识点为主要来源，保证新增知识点也能进入图谱展示。

## 后端接口

后端服务由 `app.py` 提供，主要接口如下：

```text
GET    /api/health
GET    /api/layers
GET    /api/knowledge
POST   /api/knowledge
PUT    /api/knowledge/{id}
DELETE /api/knowledge/{id}
```

其中 `/api/knowledge` 支持参数：

- `layer`：按所属层级筛选
- `q`：按标题、摘要、详情搜索
- `page`：页码
- `page_size`：每页数量
