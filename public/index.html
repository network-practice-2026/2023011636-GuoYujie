项目总览

本系统按照课程任务划分为协议可视化、综合网络访问模拟、五层模型知识库和知识图谱四个展示入口，所有演示均可在本页面直接交互验证。

01

协议可视化

展示 DNS 缓存命中/未命中、TCP 三次握手与四次挥手的报文和状态变化。

02

模拟过程

按步骤拆解 H1 访问 Web 服务器前的 ARP、DNS、TCP 和 HTTP 帧到达过程。

03

知识库

以数据库保存 TCP/IP 五层模型知识点，并通过页面完成查询、新增、编辑和删除。

04

知识图谱

使用 3D 关系图展示协议、设备、技术与层次结构，并支持节点聚焦查看详情。
